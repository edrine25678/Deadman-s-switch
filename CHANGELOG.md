## [1.0.0] - 2026-07-25

### Added
- Initial release of Deadman's Switch
- Keystroke dynamics analysis
- Facial recognition support
- Telegram bot integration for alerts
- Email backup alerts via Gmail SMTP
- Location tracking (Windows Location Service + IP geolocation)
- Screenshot and webcam capture
- Remote commands via Telegram
- Encrypted logging system
- Watchdog process for persistence
- Windows startup integration
- Configuration validation
- Calibration tools for typing and face recognition

### Security
- AES-256 encryption for event logs
- No key content storage or transmission
- Secure credential management
- Process hiding capabilities

### Documentation
- Comprehensive README
- Installation guides
- Troubleshooting sections
- Security considerations

## [0.1.0] - 2026-07-20

### Added
- Initial development version
- Basic keystroke monitoring
- Core detection engine
- Simple alert system
